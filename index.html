FPGA Order Book Engine

Fully pipelined, synthesizable NASDAQ ITCH 5.0 market data processing engine with sub-microsecond (<200ns) deterministic latency at 200 MHz. Multi-stage FSM parser, dual-sided Level 2 order book with BRAM-based hash table and insertion-sort pipeline, Q16.16 fixed-point DSP48E1 arithmetic for real-time mid-price/spread/EMA, and differential verification against a Python golden model.

SystemVerilog Vivado Artix-7 FPGA

FPGA Lock-In Amplifier (DSP & RHBD)

Radiation-hardened lock-in amplifier core with DDS reference generation, pipelined mixer, and a CIC/compensation/FIR downsampling chain. Applied RHBD via TMR on critical FSMs and Hamming ECC on config registers, verified with a UVM testbench injecting AWGN and validated on a DE10-Lite FPGA.

SystemVerilog UVM APB AMD Vivado

Matrix Multiply Accelerator (ASIC Design)

TPU-style hardware accelerator using an 8x8 systolic array for weight-stationary inference. Custom AHB subordinate interface supporting regular and burst R/W transactions, FSM controller logic, and double-buffered SRAM banks, achieving under 75 clock cycles inference latency with pipelined MAC datapaths.
